This folder is for optional exploratory work (e.g., experiments.ipynb).

Not required for CO3 (Apply) — the core pipeline runs entirely through
src/preprocessing.py, src/train.py, and src/test.py.

If you used a Colab notebook to run this project, you can export it here
(File -> Download -> Download .ipynb) as experiments.ipynb for full
reproducibility/transparency.
